Built reproducible data pipelines and visualization workflows for the CalCOFI oceanographic data modernization project.

**Highlights**
- Developed automated data ingestion and validation workflows
- Used SQL and DuckDB to organize structured marine ecosystem data
- Built interactive dashboards to support data exploration and long-term monitoring
- Presented project outcomes through a capstone poster and dashboard

**Tools:** Python, R, SQL, DuckDB, Shiny, cloud-based technologies
